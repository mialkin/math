# Прогрессия

[↑ **Прогрессия**](https://ru.wikipedia.org/wiki/Прогрессия) (_англ._ [↑ **progression**](https://en.wikipedia.org/wiki/Progression) — последовательность величин, каждая следующая из которых находится в некой, общей для всей прогрессии, зависимости от предыдущей.

## Арифметическая прогрессия

[↑ **Арифметическая прогрессия**](https://ru.wikipedia.org/wiki/Арифметическая_прогрессия) (_англ._ [↑ **arithmetic progression**](https://en.wikipedia.org/wiki/Arithmetic_progression)) — [последовательность](последовательность.md) чисел, из которых каждое следующее получается из предыдущего прибавлением постоянного числа $a$, называемого _разностью арифметической прогрессии_; например, $2, 5, 8, 11...$; $а = 3$.
